# Android Hi-Fi 老石头 — 实施计划（Route B）

## Context

个人自用、闭源的 Android Hi-Fi 老石头。用户明确：音质优先、不计硬件资源占用；架构采用 Route B（Oboe 独占输出 + 解码泵 + 无锁 SPSC 环形缓冲 + C++ DSP）；UI 用 Kotlin + Jetpack Compose；格式覆盖 FLAC/WAV/MP3/AAC/Opus/DSD/APE/WavPack；本机（Windows）无 SDK/NDK/Android Studio，需先装命令行工具链。

两种播放模式：
- **Direct**：bit-perfect 直通，DSP 全 bypass，源采样率输出（设备不支持才重采样）。
- **Processing**：所有音源统一用 `SRC_SINC_BEST_QUALITY` 升频到设备最高支持采样率（192k → 96k → 48k 探测回退）后过 DSP 链：DC/HP → PEQ → notch → crossfeed → preamp/limiter → 音量。

复用原则（已逐一核实许可证）：Oboe 1.11.0（Apache-2.0，Prefab）、libsamplerate（BSD-2）、DSPFilters（MIT，biquad 系数设计公式）、DeaDBeeF-Player/bs2b 的 `bs2b.c`（MIT，crossfeed）、rigtorp/SPSCQueue（MIT）、libebur128（MIT，ReplayGain）、FFmpeg（LGPL 动态构建，解码全部格式含 DSD/APE/WavPack）、可选 xiph/rnnoise（BSD-3，默认关）。明确禁止：sautiflow（已停更 + ViPERDSP All-Rights-Reserved + FAAD2 GPL）、任何 GPL 代码、ffmpeg-kit（停更）。

## 环境准备（第一步，Windows 本机）

1. **Android 命令行工具链**：本机已有 Java 17（AGP 8.x 满足）、git、adb；缺 SDK/NDK/cmake。下载 cmdline-tools zip（dl.google.com 官方直链）→ `sdkmanager` 安装 `platform-tools`、`platforms;android-35`、`build-tools;35.0.0`、`ndk;28.x`（16KB page size 要求，r28 或更新）、`cmake;3.22.1`；设置 `ANDROID_HOME`。
2. **Gradle**：工程内用 gradle wrapper，不需要系统 gradle。
3. **主机测试工具链**（core-dsp 的 host 单测/benchmark 用）：本机无任何编译器，也无 winget/choco/scoop，全部走官方直链：
   - cmake + ninja 直接用 Android SDK 的 `cmake;3.22.1` 包（自带 ninja，`$SDK/cmake/3.22.1/bin/`）；
   - 编译器用官方 `vs_BuildTools.exe` 引导程序静默安装 MSVC 工具链（`--add Microsoft.VisualStudio.Workload.VCTools --includeRecommended --passive --norestart`，约 3–6GB）；备选 MinGW-w64 独立 zip（winlibs.com）。
4. **磁盘**：已确认 C 盘 53GB 可用（SDK+NDK ≈5GB，FFmpeg ≈2GB，MSVC ≈4GB），足够。
5. **真机**：USB 调试；安装 OboeTester 用于独占/延迟/xrun 验证。

## 工程结构（骨架）

```
app/                Kotlin + Compose UI、MediaSessionService、音频焦点、前台服务、通知
core-dsp/           纯 C++，不依赖 Android/Oboe 头文件，host 可测：
                    biquad(TDF2)/PEQ/notch/HP/LP/crossfeed/limiter/dither/DspChain
platform-android/   Oboe 流生命周期、JNI 绑定、FFmpeg 解码泵、SRC、SPSC ring
third_party/        固定版本 vendor：bs2b.c、DSPFilters、libsamplerate、SPSCQueue、rnnoise(可选)
tests/              host 单测、golden WAV、benchmark
tools/              扫频/IR 生成、null test 脚本
docs/               线程图、RT 契约、许可清单（NOTICE）
```

## 构建与代码规范

- Gradle 8.x + AGP 8.x + Kotlin 2.x + Compose BOM；minSdk 26（AAudio MMAP 独占路径要求），targetSdk 35。
- CMake 3.22+，C++20，NDK r28+，16KB page size；Oboe 用 Google Maven + Prefab。
- 自研代码 `-Wall -Wextra -Werror`；第三方代码单独 target、隔离警告。
- **禁全局 `-ffast-math`**；用 `-ffp-contract=fast -fno-math-errno`；ARM64 开 FPCR FZ（denormal）。
- 音频回调契约：不分配、不加锁、不日志、不 JNI、不 syscall、不抛异常；`process(std::span<float>, frames) noexcept`。
- clang-format（Google）/ clang-tidy / ktlint / detekt；CMake 禁 GLOB；所有源文件 SPDX 头 + NOTICE；第三方依赖固定版本并带 LICENSE/VERSION/UPSTREAM 文件。
- FFmpeg：LGPL 配置（不开 `--enable-gpl`），动态 `.so`，构建脚本参考 mpv-android。

## 验证

- **host**：biquad 系数与 scipy 对齐；bypass null test 逐位一致；impulse/sweep 测试；每级 benchmark；ASan/UBSan。
- **设备**：OboeTester（独占/延迟/xrun）、`adb shell dumpsys media.audio_flinger`、Perfetto trace、30 分钟 0-xrun 长跑、蓝牙/USB/拔耳机/来电中断、低端机测试。
- 每个 DSP 模块 DoD：RT-safe、系数平滑与 reset、单测 + null test、benchmark、SPDX 声明。

## 里程碑

- **P0** 环境安装 + 两个 spike（Oboe 直通；FFmpeg 解码进 ring），OboeTester 验证独占可行性。
- **P1** 端到端骨架：FFmpeg → SRC → ring → Oboe 直通 + fade，Direct 模式跑通。
- **P2** Processing 模式：PEQ + AutoEQ 导入（PK/LSC/HSC + Preamp）+ limiter。
- **P3** Crossfeed（BS2B weak/strong）+ 耳机检测 + 路由/独占回退健壮性。
- **P4** MediaSession/音频焦点/前台服务/通知/gapless/seek。
- **P5** ReplayGain（libebur128）、可选 RNNoise（默认关）。

## 风险（已知）

- 独占被拒/被抢（需共享回退 + onErrorAfterClose 重开）；96/192k 设备不支持（探测回退矩阵）；蓝牙路由（延迟大，UI 提示）；温控降频（回调预算按最坏情况设计）；MediaCodec 无、FFmpeg 解码 CPU 占用（用户接受）；DSD 原生输出在 Android 不可行（转 PCM，已知限制）；16KB page size（NDK r28+）。
